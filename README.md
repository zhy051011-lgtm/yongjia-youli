# 永嘉有礼 v2 · 有据可循的文化旅行

新版网页 + 原生微信小程序 + 共用 Node.js 后端。项目运行不需要安装 npm 依赖。

当前交付为可在本地运行的完整原型，已接入 DeepSeek 并验证工具调用成功，包含网页端与原生微信小程序源码。作品按 2026 首届“永嘉农商杯”AI + OPC 创新创业大赛赛道一（AI Agent）、命题 2（永嘉特色产业）整理。演示视频需参赛者按 `docs/演示视频脚本.md` 自行录制；公网部署与小程序正式体验版二维码建议补充以便评委直接访问。

## 先打开看效果

1. 确认电脑有 Node.js 20 或以上版本。开发验证使用 Node.js 24.19.0。
2. Windows 双击 `start.bat`，保持窗口运行。或在本目录执行 `node server.mjs`。
3. 浏览器打开 \*\*<http://localhost:3188\\\\\\\*\\\\\\\*。>
4. 点击“规划我的一天”，选择需求并生成行程。没有模型密钥时，资料、规则规划、调整和导出仍能使用。

不要直接双击 `public/index.html`：页面需要连接本地后端。

## 配置 DeepSeek

在本目录用 PowerShell 运行 `powershell -NoProfile -File .\configure-key.ps1`，隐藏输入你自己的 API Key。脚本仅创建本目录 `.env`，已有 `.env` 时不会覆盖。重启后端后生效。

也可以在本机将 `.env.example` 复制为 `.env` 后自行填写。不要把密钥粘贴到聊天、源码、视频或提交包。不要将 `.env` 发给评委；评委应通过你部署的服务体验。

默认模型采用截至 2026-09-24 官方接口文档列出的 `deepseek-flash`，使用非思考模式与工具调用。可通过本地 `.env` 的 `DEEPSEEK_MODEL` 调整。已于 2026-09-27 验证真实 API 调用成功，三个工具（资料检索、行程重算、天气查询）均正常执行。

## 导入微信小程序

1. 打开微信开发者工具，导入本目录下 **miniprogram** 文件夹。
2. 项目使用 `touristappid` 占位用于本地调试；正式体验版需要你自己的小程序 AppID。
3. 先启动后端。在小程序“发现永嘉”底部设置服务地址。
4. 开发者工具模拟器可先使用 `http://127.0.0.1:3188`。开发阶段配置已关闭域名校验，只适用于本地开发。
5. 手机真机调试：使用 `start.bat` 或 `node server.mjs --lan` 启动后端；手机与电脑在同一局域网，服务地址改为电脑局域网 IP。能否连通还取决于现有网络和防火墙策略，本包不修改这些设置。
6. 正式体验版：部署 HTTPS 后端，在微信后台配置合法请求域名并启用域名校验，然后上传和扫码验证。

小程序包含发现、需求、行程结果、文化手册四个页面；不是 H5 网页的截图，也不依赖 web-view。地图及资料使用“复制链接”交互，未冒充已接入原生地图导航。

## 已实现功能

- 六条首批文化资源：芙蓉、苍坡、丽水街、瓯窑小镇、茗岙梯田、黄南林坑；每条关联公开来源。
- 日期、首站时间、兴趣、片区、交通、时长与转场缓冲设置。
- 同片区筛选、建议停留与时间预算计算；无匹配时返回空行程。
- 缩短行程、少走路、手动雨天备选、移除点位及前后变化展示。
- 网页导出 Markdown 手册、打印、本地保存并按保存需求重新计算。
- 可选真实天气查询；查询失败明确报错，不填充虚构天气。
- DeepSeek 工具接口：资料检索、行程重算、天气查询；配置后供自然语言交互使用。

## 目前边界

- 行程时间是建议分配；转场缓冲由用户设置，没有实时地图路线计算。起终点往返交通另算。
- 开放、门票、课程、无障碍和商户库存没有实时供给数据；均提示待核验，不支持预约支付。
- 雨天按钮是用户指定的情景条件，不等于实际天气。天气接口只查询县域参考点的 7 日预报。
- 知识来源中的活动多为历史报道，不能据此认定今天存在相同活动。
- 本次已配置并验证真实模型调用，尚未取得正式 AppID 和部署域名，未完成微信真机和公网体验验收。

## 验证和打包

执行 `npm test` 或 `node --test tests/planner.test.mjs tests/server.test.mjs`。

执行 `node scripts/check-miniapp.mjs` 做小程序静态检查；此命令不能替代微信开发者工具编译。

执行 `python scripts/package.py` 重新生成交付 ZIP（仅打包需要 Python 3，运行产品不需要），采用文件白名单，自动排除 `.env`、浏览器缓存和用户私有配置。压缩包位于 `deliverables/`，附 SHA-256 文件清单。

详细状态见 `docs/验收记录.md`。没有经过验证的能力，不在材料中写成已完成。
