# 评委体验说明

## 作品信息

- **作品名称**：永嘉有礼 v2
- **参赛赛道**：赛道一 · 人工智能体（AI Agent）
- **所选命题**：命题 2 · 永嘉特色产业（泵阀、文旅、现代农业、民宿经济）
- **作品定位**：有据可循的永嘉文化旅行 AI 管家

## 体验方式

### 方式一：网页端（推荐优先体验）

1. 解压 `永嘉有礼_v2_整合包.zip`。
2. 进入 `永嘉有礼_v2` 目录。
3. Windows 双击 `start.bat`，或命令行执行 `node server.mjs`。
4. 浏览器打开 `http://localhost:3188`。
5. 点击首页“规划我的一天”，选择需求后生成行程；配置 DeepSeek 密钥后可在右下角打开 AI 文旅管家对话。

### 方式二：微信小程序

1. 启动后端（同上）。
2. 打开微信开发者工具，导入 `miniprogram` 文件夹。
3. 在小程序首页点击“设置后端服务地址”，输入 `http://电脑局域网IP:3188` 或 `http://127.0.0.1:3188`。
4. 底部 tab 可切换：发现永嘉 / 我的行程 / 文化手册 / AI管家。

### 方式三：公网访问（如已部署）

若作者已部署 HTTPS 服务，可直接访问作者提供的公网地址；小程序体验需扫描作者上传的体验版二维码。

## 关键体验点

1. **规则规划**：填写日期、时间、同行人、兴趣等，观察系统如何按同片区筛选并分配时间。
2. **有据可循**：每站详情可查看公开来源链接、核验日期和出发前待确认清单。
3. **灵活调整**：行程生成后尝试“压缩到 2 小时”“少走一点路”“找雨天备选”或移除某站。
4. **AI 对话**：配置 DeepSeek 后，在网页右下角或小程序“AI管家”页面试试：
   - “你好”
   - “芙蓉古村有什么文化特色？”
   - “帮我安排一个半天的古村行程”
   - “那如果只去芙蓉古村呢？”
5. **边界提示**：注意观察系统对开放状态、历史活动、天气范围、转场时间的明确标注。

## 需要提前准备

- Node.js 20 或以上版本。
- 自己的 DeepSeek API Key（如需体验 AI 对话）；未配置时规则规划、资料、天气导出仍可正常使用。
- 微信小程序真机体验需作者提供 AppID 与体验版二维码；本包源码可用于开发者工具本地预览。

## 注意事项

- 请勿将本包内的 `.env` 文件或 API Key 对外传播。
- 行程时间为建议预算，不等于真实路程；出发前请向景区或运营方确认开放、门票与活动。
- 天气数据来自 Open-Meteo 县域参考点，不是景点逐点预报。
