## 二、API 对接方案

### DeepSeek API 集成

| 项目 | 说明 |
|------|------|
| 接口 | `https://api.deepseek.com/chat/completions` |
| 模型 | `deepseek-flash` |
| 思考模式 | `thinking: {type: 'enabled'}` |
| 工具调用 | function calling，最多 4 轮，每轮最多 5 个工具 |
| 密钥管理 | 存于服务器环境变量 `DEEPSEEK_API_KEY`，前端不可见 |
| 超时保护 | 单次请求 25 秒，API 层并发上限 2，每日上限 100 次 |

### 后端 API 端点

| 端点 | 方法 | 功能 | 鉴权 |
|------|------|------|------|
| `/api/health` | GET | 健康检查、AI 配置状态 | 无 |
| `/api/resources` | GET | 6 条文化资源库 | 无 |
| `/api/plan` | POST | 规则规划（时间预算+同片区筛选） | 无 |
| `/api/weather` | GET | Open-Meteo 真实天气 | 无 |
| `/api/agent` | POST | AI Agent 对话（DeepSeek 工具调用） | 无（速率限制） |

### 安全措施

- **CSP 头**：`default-src 'self'`，禁止外部脚本注入
- **CORS Origin 检查**：验证请求来源匹配预期域名
- **速率限制**：每 IP 每分钟 80 次普通请求，AI 接口每 IP 每分钟 6 次
- **请求体大小限制**：64KB
- **密钥隔离**：DeepSeek 密钥仅在服务器端使用，小程序和网页不接触密钥

## 三、页面嵌入与访问方式

### 方式一：网页直接访问（评委推荐）

评委拿到 HTTPS 链接后，直接在浏览器打开即可体验全部功能，包括 AI 对话。

- 网页端自带 AI 助手对话框（右下角）
- 无需安装任何软件
- 支持桌面和手机浏览器

### 方式二：微信小程序

评委若有微信开发者工具，可导入 `miniprogram/` 目录体验原生小程序。

- 4 个页面 + 1 个 AI 管家页面
- 底部 tab：发现永嘉 / 我的行程 / 文化手册 / AI管家
- 需在首页设置后端服务地址

### 小程序与后端的对接

```
小程序 (wx.request)
    ↓
POST https://部署地址/api/agent
    body: { message, history, profile }
    ↓
返回: { text, plan, steps, model }
```

小程序不嵌入网页（非 web-view），使用原生 WXML/WXSS 页面，通过 `wx.request` 调用后端 API。

## 四、Render 部署方案

### 部署架构

```
Render (Docker 容器)
  ├── Node.js 24 Alpine
  ├── server.mjs (监听 0.0.0.0:3188)
  ├── public/ (静态网页)
  ├── lib/ (后端逻辑 + AI Agent)
  └── 环境变量: DEEPSEEK_API_KEY, ALLOWED_ORIGIN
```

### 部署步骤

1. **推送代码到 GitHub**
   - 在 GitHub 创建仓库 `yongjia-youli`
   - 项目目录执行 `git push`

2. **在 Render 创建服务**
   - 登录 https://dashboard.render.com
   - New → Web Service → 连接 GitHub 仓库
   - Render 自动读取 `render.yaml` 配置
   - 环境变量填写：
     - `DEEPSEEK_API_KEY`：DeepSeek 密钥
     - `ALLOWED_ORIGIN`：部署后的 HTTPS 地址

3. **部署完成**
   - Render 分配地址：`https://yongjia-youli.onrender.com`
   - 健康检查：`/api/health` 返回 `aiConfigured: true`
   - 评委直接访问该地址即可体验

### 环境变量

| 变量 | 值 | 说明 |
|------|------|------|
| `DEEPSEEK_API_KEY` | （服务器配置，不公开） | DeepSeek API 密钥 |
| `DEEPSEEK_MODEL` | `deepseek-flash` | 使用的模型 |
| `PORT` | `3188` | 服务监听端口 |
| `ALLOWED_ORIGIN` | `https://yongjia-youli.onrender.com` | 允许的网页来源 |
