# 部署与微信导入

本文件是部署方案，不代表已经部署。当前本地地址不能交给外网评委直接访问。

## 本地

启动命令 `node server.mjs`，默认只监听 127.0.0.1:3188。局域网调试使用 `node server.mjs --lan`。`start.bat` 默认使用局域网模式；不修改系统防火墙、注册表或 PATH。

服务读取项目根目录 `.env`。配置密钥后必须重启；不要把 API 密钥写入网页或小程序。

## 服务器

1. 选定用户授权的服务器和域名，安装合适的 Node.js 或使用项目提供的 Dockerfile。
2. 上传 `public`、`lib`、`server.mjs`、`package.json`；不上传本地 `.env`、缓存和其他项目文件。
3. 在服务器单独设置模型密钥，用进程管理器运行应用。
4. 用已有反向代理提供 HTTPS，将请求转发至应用端口。
5. `.env` 中 `ALLOWED_ORIGIN` 设置为实际网页来源，例如自己的 `https://域名`，不带结尾斜杠。
6. 验证首页、资料、规则规划、真实 AI 问答、天气失败提示，并用其他网络测试访问。

Dockerfile 为部署模板，本次未构建容器或配置反向代理。

## 微信

`miniprogram` 是可导入源码目录。`project.config.json` 的 touristappid 为调试占位；用自己的 AppID 后再进行上传。小程序只接触后端地址，不接触 DeepSeek 密钥。

本地调试关闭合法域名检查不等于正式体验版可以使用 HTTP/IP。正式版需按微信后台要求配置 HTTPS 请求域名；把 `urlCheck` 改回 true，上传体验版，按平台要求添加体验人员并验证二维码。

当前小程序支持复制地图查询和官方来源链接；没有接入地图小程序跳转或已授权的 web-view 业务域名。
