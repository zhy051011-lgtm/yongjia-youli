## 三、Render 部署步骤

### 1. 推送代码到 GitHub

在项目目录打开终端：
```
cd C:\Users\小赵\Desktop\永嘉有礼_v2_整合包\永嘉有礼_v2
git remote add origin https://github.com/你的用户名/yongjia-youli.git
git push -u origin master
```

### 2. 在 Render 创建服务

1. 打开 https://dashboard.render.com
2. 点击 New → Web Service
3. 连接你的 GitHub 仓库
4. Render 会自动读取 `render.yaml`
5. 在环境变量中填入：
   - `DEEPSEEK_API_KEY` = 你的 API Key
   - `ALLOWED_ORIGIN` = 部署后的地址（如 `https://yongjia-youli.onrender.com`）
6. 点击 Create Web Service
7. 等待部署完成，Render 会给你一个 HTTPS 地址

### 3. 将地址同步到小程序

部署成功后，在小程序首页"设置后端服务地址"改为该 HTTPS 地址。
